# ประกาศความเป็นส่วนตัวสำหรับผู้รับบริการ

**เวอร์ชัน 1.0 · เริ่มใช้ 22 กันยายน 2569**

ประกาศนี้อธิบายว่า Payung เก็บข้อมูลอะไรของคุณ เอาไปทำอะไร ใครได้เห็นบ้าง เก็บไว้นานแค่ไหน และคุณมีสิทธิ์อะไร

> ประกาศฉบับนี้ใช้กับ **ผู้รับบริการและครอบครัว** ผู้ดูแลมีประกาศแยกอีกฉบับ

---

## 1. ใครเป็นผู้เก็บข้อมูลของคุณ

ทีมงาน Payung เป็นผู้ควบคุมข้อมูลส่วนบุคคล ติดต่อเรื่องข้อมูลส่วนบุคคลได้ที่ **privacy@payung.app**

---

## 2. เราเก็บข้อมูลอะไรบ้าง

### 2.1 ข้อมูลทั่วไป

| ข้อมูล | เก็บตอนไหน |
| --- | --- |
| ชื่อ นามสกุล ชื่อเล่น | ตอนกรอกข้อมูลครั้งแรก |
| อีเมล เบอร์โทรศัพท์ | ตอนสมัคร |
| ที่อยู่ ตำบล อำเภอ จังหวัด รหัสไปรษณีย์ | ตอนกรอกข้อมูลครั้งแรกและตอนจอง |
| รูปโปรไฟล์ | เมื่อคุณเลือกอัปโหลด (ไม่บังคับ) |
| ประวัติการจองและการชำระเงิน | ทุกครั้งที่จอง |

### 2.2 ข้อมูลสุขภาพ — ข้อมูลที่กฎหมายคุ้มครองเป็นพิเศษ

ข้อมูลสุขภาพเป็น **ข้อมูลส่วนบุคคลอ่อนไหวตามมาตรา 26 แห่ง พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562** เราจะเก็บก็ต่อเมื่อคุณ **กดยินยอมโดยชัดแจ้งแยกต่างหาก** เท่านั้น

- อายุ เพศ น้ำหนัก ส่วนสูง
- ระดับการช่วยเหลือตัวเอง
- โรคประจำตัว ยาที่ใช้ประจำ ประวัติการแพ้ยาและอาหาร กรุ๊ปเลือด
- คำแนะนำการดูแล และโรงพยาบาลที่ใช้บริการประจำ
- บันทึกการดูแลและรูปถ่ายระหว่างปฏิบัติงานที่ผู้ดูแลบันทึกไว้

### 2.3 ข้อมูลที่เก็บอัตโนมัติ

- หมายเลขไอพีและชนิดของเบราว์เซอร์ **เฉพาะตอนที่คุณกดยินยอม** เพื่อเป็นหลักฐานว่าความยินยอมเกิดขึ้นจริง
- เวลาเข้าใช้งานล่าสุด
- ตำแหน่งที่ตั้งตอนผู้ดูแลเช็คอิน/เช็คเอาท์ (เพื่อยืนยันว่าไปถึงจริง)

**เราไม่เก็บ**: เลขบัตรเครดิตหรือเลขบัญชีธนาคารฉบับเต็ม การชำระเงินดำเนินการโดย Omise ระบบของเราเก็บเพียงเลขท้าย 4 หลักไว้ให้คุณดูว่าจ่ายด้วยบัตรใบไหน

## 3. เราเอาข้อมูลไปทำอะไร

| วัตถุประสงค์ | ฐานทางกฎหมาย |
| --- | --- |
| สร้างและดูแลบัญชีผู้ใช้ | การปฏิบัติตามสัญญา |
| จับคู่ผู้ดูแลที่เหมาะกับอาการและพื้นที่ของคุณ | **ความยินยอมโดยชัดแจ้ง** (ข้อมูลสุขภาพ) |
| ส่งข้อมูลให้ผู้ดูแลที่รับงาน เพื่อให้ดูแลได้ถูกต้องและปลอดภัย | **ความยินยอมโดยชัดแจ้ง** |
| รับชำระเงิน ออกใบเสร็จ และคืนเงินเมื่อยกเลิก | การปฏิบัติตามสัญญา และหน้าที่ตามกฎหมาย |
| แจ้งเตือนสถานะการจองทางอีเมลและในแอป | การปฏิบัติตามสัญญา |
| ตรวจสอบข้อร้องเรียนและระงับข้อพิพาท | ประโยชน์อันชอบด้วยกฎหมาย |
| ส่งข่าวสารและโปรโมชัน | **ความยินยอม** (ปฏิเสธได้ ไม่กระทบการใช้บริการ) |

เรา **ไม่ขาย** ข้อมูลของคุณ และ **ไม่ใช้** ข้อมูลสุขภาพเพื่อการตลาด

## 4. ใครได้เห็นข้อมูลของคุณ

| ผู้รับข้อมูล | เห็นอะไร | เมื่อไหร่ |
| --- | --- | --- |
| ผู้ดูแลที่รับงานของคุณ | ชื่อ ที่อยู่ที่ให้บริการ และข้อมูลสุขภาพที่คุณกรอก | หลังรับงานเท่านั้น |
| ผู้ดูแลที่ยังไม่ได้รับงาน | ไม่เห็นข้อมูลของคุณเลย | — |
| สมาชิกกลุ่มครอบครัวของคุณ | นัดหมาย สถานะงาน และข้อมูลผู้รับบริการ | เมื่อคุณยินยอมข้อกลุ่มครอบครัว |
| Omise (ผู้ให้บริการรับชำระเงิน) | ข้อมูลที่จำเป็นต่อการตัดบัตร/พร้อมเพย์ | ตอนชำระเงิน |
| Supabase (ผู้ให้บริการฐานข้อมูลและพื้นที่เก็บไฟล์) | เก็บข้อมูลตามคำสั่งของเรา | ตลอดเวลาที่ใช้บริการ |
| หน่วยงานรัฐ | เท่าที่กฎหมายบังคับ | เมื่อมีคำสั่งตามกฎหมาย |

## 5. เก็บไว้นานแค่ไหน

| ข้อมูล | ระยะเวลา |
| --- | --- |
| ข้อมูลบัญชีทั่วไป | ตลอดเวลาที่บัญชียังเปิดอยู่ |
| ข้อมูลสุขภาพและบันทึกการดูแล | **2 ปี** หลังปิดบัญชี แล้วลบ |
| เอกสารการเงินและใบเสร็จ | **5 ปี** ตามที่กฎหมายบัญชีและภาษีกำหนด |
| บันทึกความยินยอม | **5 ปี** เพื่อพิสูจน์ได้ว่าความยินยอมเกิดขึ้นจริง |

บันทึกความยินยอมเก็บนานกว่าตัวข้อมูลโดยตั้งใจ — ถ้าลบพร้อมกัน เราจะพิสูจน์ไม่ได้ว่าเคยได้รับความยินยอมมาโดยชอบ

---

## 6. สิทธิ์ของคุณ

คุณมีสิทธิ์ตามกฎหมายดังนี้ ใช้สิทธิ์ได้โดยติดต่อ **privacy@payung.app**

1. **ขอดูข้อมูล** ที่เรามีเกี่ยวกับคุณ และขอสำเนา
2. **ขอแก้ไข** ข้อมูลที่ไม่ถูกต้องหรือไม่เป็นปัจจุบัน
3. **ขอลบ** ข้อมูล หรือทำให้ไม่สามารถระบุตัวคุณได้
4. **ขอให้หยุดใช้** ข้อมูลชั่วคราว
5. **คัดค้าน** การเก็บหรือใช้ข้อมูลในบางกรณี
6. **ขอย้ายข้อมูล** ไปยังผู้ให้บริการรายอื่นในรูปแบบที่อ่านได้ด้วยเครื่อง
7. **ถอนความยินยอม** ได้ทุกเมื่อ
8. **ร้องเรียน** ต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล

เราจะตอบกลับภายใน **30 วัน** นับแต่วันที่ได้รับคำขอ

**การถอนความยินยอม** ไม่กระทบการใช้ข้อมูลที่เกิดขึ้นไปแล้วก่อนหน้านั้น และถ้าถอนความยินยอมเรื่องข้อมูลสุขภาพ คุณจะจองผู้ดูแลต่อไม่ได้ เพราะเราไม่มีข้อมูลพอที่จะจับคู่ผู้ดูแลได้อย่างปลอดภัย

---

## 7. เราดูแลข้อมูลของคุณอย่างไร

- ข้อมูลเข้ารหัสระหว่างรับส่ง และฐานข้อมูลจำกัดสิทธิ์การเข้าถึงเป็นรายแถว
- รูปถ่ายและเอกสารเก็บในพื้นที่ปิด เปิดดูได้ผ่านลิงก์ชั่วคราวที่หมดอายุเท่านั้น ไม่ใช่ลิงก์สาธารณะ
- รูปถ่ายที่อัปโหลดถูกลบข้อมูลพิกัดและข้อมูลกล้องออกก่อนจัดเก็บ
- พนักงานเข้าถึงข้อมูลได้เท่าที่จำเป็นต่อหน้าที่

---

## 8. เด็กและผู้ไร้ความสามารถ

บริการนี้สำหรับผู้ที่มีอายุ 20 ปีขึ้นไป หากผู้รับบริการเป็นผู้เยาว์ คนไร้ความสามารถ หรือคนเสมือนไร้ความสามารถ ผู้ที่กรอกข้อมูลต้องเป็นผู้ปกครองหรือผู้อนุบาลตามกฎหมาย และรับรองว่ามีอำนาจให้ความยินยอมแทนได้

---

## 9. เมื่อประกาศนี้เปลี่ยน

ถ้าเราเปลี่ยนสาระสำคัญ เช่น เพิ่มวัตถุประสงค์ เพิ่มผู้รับข้อมูล หรือเปลี่ยนระยะเวลาเก็บ เราจะขึ้นเวอร์ชันใหม่และขอความยินยอมจากคุณอีกครั้งก่อนใช้บริการต่อ

การแก้คำผิดหรือจัดรูปแบบหน้าใหม่จะไม่ขึ้นเวอร์ชัน และไม่ขอความยินยอมใหม่
