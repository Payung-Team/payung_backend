# Payung API 🌂

Backend API for the Payung application, providing services for caregiving, booking, identity management, and payments.

## 🛠 Tech Stack
- **Framework:** NestJS (Node.js)
- **API Gateway:** GraphQL (Apollo, Code-First approach)
- **Database & Storage:** Supabase (PostgreSQL)
- **Payment Gateway:** Omise (External Service)
- **Language:** TypeScript

## 📋 Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)
